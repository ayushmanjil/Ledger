# Ledger

Ledger is a personal finance management web application designed for tracking income, expenses, wallets, monthly budgets, savings goals, and debts. Built with React, TypeScript, Tailwind CSS, and Firebase, it features real-time data sync, dynamic financial analytics, and responsive design across desktop and mobile devices.

The application offers customizable visual design systems—including an **Artisan Leather Surface** mode and an **Apple-inspired Frosted Crystal Glass** mode with custom color themes—providing a refined and modern personal accounting workspace.
